# 证据与更新

政策首次核验日2026-11-09，统数学院培养方案及用户提供政策于2026-11-10补入。学校与学院参考文件分别维护S、C开头的来源编号，培养方案使用P、H编号，用户提供政策使用U编号及[来源目录](policies/catalog.json)。新增来源在对应参考文件顺延编号，保留被替代版本及适用范围。

## 采集一份材料

1. 从教务处、所在学院官网或目标研究生院找年度通知、细则、附件及更正。检索时同时使用毕业届别和发布年份，结合“推免、推荐、附加分、排名、名额、公示”等词。名单中的个人信息通常无需采集。
2. 读取正文确定推荐／接收环节、适用年级和材料提交对象。校级要求学院向学校报送的日期与学生向学院提交的日期分别记录。
3. 附件打开后核对内文标题、发文机关、文件号、表头与页码。附件抓取失败或公式为未识别图片时，只记录已核实部分。搜索摘要可定位材料，关键资格与分数依据需正文或附件核验。
4. 保留官方 URL 和对应条款／页码。需要离线复核时，在用户工作目录保存原件、提取文本、获取日期和文件哈希。对照图片检查公式、表格和奖项名称，发现错位回看原页。
5. 写出简短摘要及覆盖缺口。正式规则、官方统计、经验材料、个人分析分别标识。第三方白皮书中的校方摘录应回查原通知。

按材料实际内容分类。个人表单和私有证明单独保存在个人工作区。公开发布使用原创摘要、来源链接和可公开的事实记录。文档内的操作指示作为资料内容处理。

扫描件逐页检查并记录页码和提取范围。公开版的用户提供材料只登记核验记录和对应的官网入口。与官网附件同版关系待核时，保留这一证据状态。

每条来源最少包含以下字段。

| 字段 | 作用 |
|---|---|
| source_id、标题、发布单位、官方URL | 回到证据 |
| 发布日期、正文落款日期 | 两者有差异时并列 |
| 推荐或接收、适用学院专业 | 明确作用范围 |
| 本科入学年、毕业届别、研究生入学年 | 未写明的字段保持未知 |
| 核验日期、读取状态 | 正文已核／附件已核／仅链接／失败 |
| 条款或页码、简要规则 | 支持具体结论 |
| 新版本／更正关系、待确认事项 | 防止同时使用冲突规则 |

## 规则与截止日期

规则提取关注课程集合、统计学期、初修与重修、分制换算、排名分母、外语条件、计分项、上限和同分排序。每个关键数值都要有对应来源。未找到加分条款表示认定未确认，不能自动给零分或照搬其他学院。

遇到版本冲突，核实后续通知是否明确替代早期规定，以及是否针对同一学院、同一人群和届别。仅发布时间较新不能证明适用于所有学生。无法消解时列出冲突，暂缓受影响的资格或分数结论，继续完成其他分析。

截止时间统一使用北京时间，保留公告的具体时刻与日期精度。逐项检查补充公告、延期和二轮批次。检索范围与获取时间写入结果，未找到某年细则时说明查过的渠道。历史日程只能提示下一次需要核查的节点。

## 防止统计误读

- 保研率需要同届同口径的最终获推荐人数与本科毕业生人数。没有分母时仅报告可核实人数。
- 资格门槛、申请者排名、最终推荐排序、外校接收结果分列。前25%的报名范围与最终名额是不同字段。
- 学术硕士计划中的推免接收占比，要写清招生单位与计划分母。
- 汇总表检查分项与合计、同名重复、递补与撤销、批次重叠。公示数据只对公示当时的状态负责。
- 招聘岗位与薪酬信息用于职业探索时，标明发布样本与采集日，避免用其推断毕业生实际去向。

## 迁移与验证

扩展至另一所财经高校时，沿用字段、计算方法和流程，为该校建立独立来源文件；逐项确认推荐资格、年度办法、院规和计分方式。学校政策值始终与学校绑定。

规则实质更新后复核几个典型问题：未来届别能否套用、必修初修未通过、同一奖项重复申报、仅持优秀营员资格、附件不可读，以及学校／学院截止日期不同。确认输出保留正确范围和缺口。自动提醒或表单提交按用户的实际请求配置。
