# 吉林财经大学保研 Skill

当前版本 **v0.6.28**。本版将学院政策拆为独立入口。查询个人校内推免时，先确认学籍学院、专业全称及方向、学籍班或原专业班、入学年，再查对应学院和届别的资料。

重点覆盖统计与数据科学学院七个专业／方向，以及国际教育学院金融学（中外合作办学）2027 届推免。另收录金融学院、经济学院、税务学院的已核资料和 19 个外校及科研院所项目入口。

## 使用方式

- **支持 Skill 的客户端**。保留完整的 `jlufe-baoyan/` 目录，按客户端说明导入或安装。 [Skill 入口](jlufe-baoyan/SKILL.md) · [各平台接入与版本记录](jlufe-baoyan/read.md)
- **普通对话**。复制对话指令，按任务提供对应参考文件。 [对话指令](CHAT-PROMPT.md)
