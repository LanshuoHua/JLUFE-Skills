# 吉林财经大学保研 Skill 使用与版本记录

当前版本 **v0.6.28**。面向吉林财经大学本科生，重点覆盖统计与数据科学学院七个专业或方向，以及国际教育学院金融学（中外合作办学）2027 届推免。维护 19 个外校及科研院所项目入口。实际报名以当届公告及办理单位答复为准。

## 使用方法

1. 从 GitHub Releases 下载独立 Skill ZIP。支持 ZIP 导入的宿主可直接上传 ZIP。需要手动安装时先解压，保留完整的 `jlufe-baoyan/` 文件夹和相对路径。更新后检查 `SKILL.md` 中的版本。 [Skill 入口](SKILL.md)
2. 查询个人校内推免时，提供**学籍学院、专业全称及方向、学籍班或原专业班、入学年**。班级可以用脱敏班号，无独立分班可直接说明。需要测算时，再提供排名、成绩和脱敏材料。 [个人信息模板](assets/profile-and-evidence.md)
3. Skill 确认学籍后只查对应学院与届别。查外校时提供目标学校、院系、专业和招生年度。复算均分时，从吉财教务系统查本人教学计划、学分和初修成绩，再用适用表格填报。 [学院政策索引](references/college-policy.md) · [历年通知](references/jlufe-notice-index.md) · [外校项目](references/target-programmes.md) · [逐课填报表](assets/theoretical-course-records.md)
4. 起草推免文书时，先选目标项目和文书类型，再复制相应模板。普通对话中可只提供所需模板和脱敏经历。 [文书模板索引](references/application-documents.md)

> 使用 jlufe-baoyan。我是吉财统计与数据科学学院 2024 级金融数学 1 班学生，想申请东北师范大学统计学。请核对校内适用规则和目标项目，列出已知条件、待查的当届文件和需要我补充的材料。

## 接入各家模型和客户端

以下是按官方文档核对的接入路径。Skill 的发现、文件读取、联网和 Python 运行取决于宿主及账号权限。安装后可先试问「我是吉财金融学的，四级 425 能保研吗？」检查宿主是否先问清学院、专业方向、班级和入学年。补齐后，检查引用是否来自对应学院与届别。

| 客户端 | 安装与调用 |
|---|---|
| **OpenAI Codex 桌面、CLI 或 IDE** | 把解压后的文件夹放到项目的 `.agents/skills/jlufe-baoyan/`。在 Codex 中用 `$jlufe-baoyan`，CLI 或 IDE 也可用 `/skills` 选择。桌面侧栏的 Skills 可查看已识别技能。 [OpenAI Docs](https://learn.chatgpt.com/docs/build-skills) |

| **Claude 网页** | 账号有自定义 Skills 时，在 Settings 的 Capabilities 开启代码执行和文件创建，再进入 Customize → Skills → 创建 Skill → Upload a skill，上传独立 ZIP。团队账号的开关由管理员管理。 [Claude 官方帮助](https://support.claude.com/en/articles/12512180-use-skills-in-claude) |

| **豆包工作** | 在侧栏的「技能·连接器·伙伴」打开技能页，选择导入本地技能文件，再从输入框的「更多技能」调用。以当前客户端校验结果为准。通过豆包开放平台公开上架另有企业认证、资源格式和审核要求。 [豆包工作官方产品说明](https://www.feishu.cn/content/article/7677519271848610746) · [豆包开放平台指南](https://open.doubao.com/document/doubao-developer-guide/skill-integration-guide) |

### 普通对话或自建智能体

1. 上传 [SKILL.md](SKILL.md)，或将其正文粘贴进对话。查个人校内推免时，先补齐学籍信息，再从[学院政策索引](references/college-policy.md)选取对应学院和届别的资料上传或粘贴。
2. 查外校接收时，提供目标项目对应的参考页。请模型写明适用院系、专业和届别，列出处与待核事项。
3. 自建智能体可以把 `SKILL.md` 作为工作指令，先收集学籍字段，再按学院、专业和届别筛选参考资料。使用脚本时，在自己的 Python 环境运行。OpenAI Responses API 也提供上传 Skill ZIP 后在 Shell 工具环境引用技能 ID 的入口。 [OpenAI API Skills](https://developers.openai.com/api/docs/guides/tools-skills)

在解压后的 `jlufe-baoyan/` 内运行下列命令，可以用合成数据复算。示例均分为 `84.0000`。 [复算说明](references/course-calculation.md)

```powershell
python scripts/weighted_average.py assets/course-input.example.json
```
