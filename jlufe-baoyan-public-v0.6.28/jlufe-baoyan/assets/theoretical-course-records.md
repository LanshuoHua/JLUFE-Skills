# 吉林财经大学理论必修课逐课填报表

## 理论必修逐课记录

收录**通识必修、学科必修、专业必修中的理论课**。四年制正式推免复算核对培养方案规定的第三学年结束前应修课程。在低年级提前测算时，先填截至所选学期已应修且有初修成绩的课程，并注明统计学期。发现漏修、缓考或未出分的应修课程时也列一行，写明状态。

|---|---|---|---|---:|---|---|
| | | 通识必修 | | | | |
| | | 学科必修 | | | | |
| | | 专业必修 | | | | |

- 学分按本人适用的教学计划或学院核定值填写。板块、理论与实践属性、混合课可计学分无法判断时填「待核」，有教学计划截图或学院答复可在备注注明。
- 初修成绩照录系统分数或等级，如「优秀」「及格」「不及格」。补考或重修写在备注。系统仅显示补考或重修结果时，初修成绩填「待核」。跨学期开设的不同课程可分行，同一门课的不同考试记录集中在一行。
