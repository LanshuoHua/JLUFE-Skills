# 学院推免政策索引

先按 [Skill 入口](../SKILL.md) 确认学生的学籍学院、专业全称、班级和入学年。按已确认的学院只打开对应政策页，再在该页匹配当届通知及适用专业或班级。

| 学籍学院 | 政策入口与来源 |
|---|---|
| 统计与数据科学学院（含适用过渡政策的原统计学院、原应用数学学院学生） | [统数学院政策](statistics-policy.md)，C06、U02、U03。按入学年和学籍专业进入适用原学院分支，按确认的原专业班核对排名与配额。 |
| 国际教育学院 | [金融学（中外合作办学）专项](international-education-policy.md)，C07、U07、T25。其他专业或缺少当届材料时，查本院对应文件。 |
| 金融学院 | [金融学院政策](finance-college-policy.md)，C03、C04。按当届有效文件使用。 |
| 经济学院 | [经济学院政策](economics-policy.md)，C01、C02。按当届有效文件使用。 |
| 税务学院 | [税务学院政策](taxation-policy.md)，C05。已收录 2027 届通知。 |

会计学院及其他未收录院规的学院，查对应学院、专业和届别的有效通知与附件。现有资料中的会计学院经验只能说明个人申请过程。缺少本院文件时，只引用已核实的[校级基础条件](school-policy.md)，院级资格、课程、加分、排名和名额标为待核。 [会计学院官网](https://newkjxy.jlufe.edu.cn/)

[历年通知与附件索引](jlufe-notice-index.md)用于定位文书和历史批次。按已确认的学院和届别读取对应章节，[学校政策](school-policy.md)用于核对校级条款。
