# 目标项目与申请流程

本校推荐个案先按 [Skill 入口](../SKILL.md) 确认学籍归属，再读取校级和对应学院政策。目标院校可包含吉林财经大学，也可为其他学校。每个项目都单独核验当年接收条件。

目标为吉林财经大学时，先查研究生院当年接收章程、接收专业及招生公示。历史章程与官网PDF入口单列在接收部分。吉财本科生申请本校推荐资格时，使用同一索引的校内推荐部分。 [历年通知与附件索引](jlufe-notice-index.md)

## 建立项目记录

用户给出意向学校时，从其研究生院和目标学院官网获取材料。尚无目标时先收集方向、学位偏好、城市／费用约束和学术背景，再核验候选。学校名、学院名、专业代码、学位类型、培养方式共同确定一个项目，保留夏令营、预推免和正式接收各批次。

按[外校项目索引](target-programmes.md)核对目标年份的接收公告。确认是统数学院学生后，可另按适用原学院和学籍专业查询[历年推免去向](statistics-destinations.md)与[外校推免准备](statistics-application-planning.md)。

项目表记录官方公告URL、适用研究生入学年、发布日、核验日、申请系统、截止时间、资格与专业限制、英语考试种类和最低分、排名范围、材料清单、初审与考核形式、结果有效条件。公告如列明成绩有效期或材料评分权重，一并记录。费用或培养安排未明时列为待核实。未发布未来年度规则的项目保留历史参考标记。

用个人背景对照明确门槛，之后分析基础课、研究兴趣、方法能力与项目要求的匹配。不依据学校层级标签单独判断难度。缺少校本样本时，采用门槛和匹配度分组，保留申请结果的不确定性。

## 申请状态

同时跟踪三条时间线。夏令营和预报名按接收院校各批次的公告及截止时间办理，符合当批条件时可与本校推荐并行。校内推荐按本校通知完成申请、审核和公示。正式推免接收按目标院校及研招网要求核对推免资格、志愿、复试和待录取通知。校内资格和入营、优秀营员、拟接收等状态分项记录。

判断某日能否报名时，分别核对公告发布日期、报名开放时间、截止时间与考试或活动日期。后来发布的公告可用于复盘，单独标明发布日期。只有历史活动摘要时，先核公告正文和对应批次的开放状态。

候补来电、已填志愿、复试通知、复试已确认、待录取通知和待录取已确认分项记录。按招生单位给出的时限和系统有效状态办理。研招网只允许确认一条待录取通知，确认后将结束其他志愿的后续操作。 [学信网待录取说明](https://kl.chsi.com.cn/wap/help/ckjjfa.action?id=3ted4fgnirqzr64p)

优秀营员或口头意向的后续条件逐条核查，特别是本校资格、专业名额、再次报名与系统操作。系统报名、接受通知、放弃资格以及联系导师应按用户明确指令执行，拟稿任务先产出可审阅文本。

## 材料与面试

对照目标清单检查成绩单、排名证明、英语证书、在读材料、科研与竞赛证明、个人陈述、简历和推荐材料。内容以用户真实经历为基础，标注合作者与个人贡献。提供材料时遮蔽与申请判断无关的身份证、住址等字段。

排名证明、全课程成绩单与预计获得推免资格证明分别核对出具部门、时间和字段。目标项目要求提前提交时，查该批是否允许替代材料或补交。先确认本科学籍归属，再查本院办理方式。统数学院办理口径见[专项准备页](statistics-application-planning.md)。

文书先围绕一个真实项目核查问题、数据、方法、本人贡献、结果与局限，再按目标方向调整重点。按文书类型选择可填写的模板，并检查排名、外语、成果状态和提交要求。推荐信草稿由推荐人审阅，签名、盖章和提交按目标院校要求由相应主体完成。 [推免文书模板与核对](application-documents.md)

面试依据目标专业考核内容设置题目，覆盖专业基础、英语表达、研究经历追问和方法局限。模拟题标为训练题。把回答错误转成需要复习的知识点，避免把答题表现直接换算为录取概率。

截止日期与提醒使用公告规定的北京时间。设置提醒须来自用户请求；材料中列出的建议核查日期仅用于当前规划。
