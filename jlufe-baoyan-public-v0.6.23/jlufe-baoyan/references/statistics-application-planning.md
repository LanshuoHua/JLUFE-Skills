# 统数学院外校推免准备

适用于吉林财经大学统计与数据科学学院学生规划理学、工学及相关应用统计项目。2026-11-10收录用户提供的备考经验。英语、排名档位用于制定准备计划。资格、材料初筛和考核按各校各项目当届公告确认。校内推荐资格另查校级和学院办法。 [校内推荐规则](statistics-policy.md)

## 英语和排名怎样设目标

六级按425–459、460–499、500–519、520–549、550–599、600及以上分档。以425为第一备考目标，争取达到460，有余力继续争取500。520、550、600是进一步提升的档位，结合目标项目和科研、课程投入安排。用户的理工类申请经验把550作为提升目标。具体项目的六级、四级、雅思或其他考试要求逐项核对。

雅思6.5及以上可和六级500及以上放在相近的备考层次作个人规划参考。申请时分别核对项目是否接受相应考试、最低分、分项要求和成绩有效期。按公告承认的成绩种类提交证明。

### 排名档位

排名同时记录名次和总人数，例如`1/60`。说明排名所属专业、年级、统计学期及计算口径，优先使用目标院校要求的教务证明。校内按班核算的推免资格排名另行记录。个人规划可按以下档位比较。

| 档位 | 百分比 `p = 100 × 名次 ÷ 总人数` |
|---|---|
| 前1% | `p ≤ 1` |
| 前3% | `1 < p ≤ 3` |
| 前5% | `3 < p ≤ 5` |
| 前5%之后 | `p > 5` |

Rank 1单独注明。例如`1/60`仍是第一名，计算比例约1.67%。目标项目的并列、人数和比例取整按其公告处理。据用户观察，吉财已有985工程院校推免去向的同学通常处于第一名或较靠前的名次。完整的录取者排名和分母尚待补齐，按个案规划。 [历史去向](statistics-destinations.md)

### 排名证明与成绩单

按用户确认的办理口径T19，统数学院学生向**学院教学秘书**登记开具专业排名证明，向**学校教务处**开具全课程成绩单。某学期成绩公布后，可申请截至该学期的累计专业排名证明。证明列明**专业总人数和本人专业名次**，未注明排名使用的课程范围。目标项目要求说明具体课程口径时，向学院教学秘书核实后填写。办理所需材料和出具用时待核。 [来源目录](policies/catalog.json)

套磁和夏令营通常早于第六学期成绩公布，大三下先准备前五学期排名证明，写明统计截止学期。第六学期成绩公布后，可在项目允许的窗口更新证明。提交前核对目标项目要求的统计学期、排名口径和签章。校内推免资格排名另按学院规则核对。 [申请材料核对](application-workflow.md)

**预计获得推免资格证明（T21）。** 按用户确认的办理口径，统数学院在校内推免资格正式公示前不开具这份证明。遇到外校预推免要求提前提供时，查看目标项目是否接受其他材料或允许按指定时限补交，按实际状态填写资格。具体公示层级与公示后的证明办理流程待核。 [申请材料核对](application-workflow.md)

## 简历初筛怎样准备

用户提供的经验顺序可作为简历核查清单。官方公布的院校范围、排名、英语门槛及材料评分在对应项目表中单独填写。

1. 本科院校与学科背景。列学校、专业、匹配的核心课程和受过的训练。项目若按本科院校或学科范围筛选，读取其明确条件。
2. 学业排名。把教务可证明的名次、人数和学期放在简历显眼处。申请条件要求百分比时提供原始名次及分母。
3. 外语成绩。按目标项目口径提供可核验成绩，尽早留出报名与出分时间。
4. 科研经历。对研究导向项目，在满足其基本条件后，优先把研究经历做深。用问题、方法、本人贡献和可检查成果说明能力，再对照目标方向解释匹配。
5. 竞赛及其他经历。精选专业相关、评审和获奖层级可核实的成果，标明赛道、级别、名次和本人贡献。

各校公告列明的初审或复试权重按项目记录。只给考察因素时，逐项准备证明材料。研究、排名和英语相互补充，准备时间优先给能解决当期门槛或形成可展示成果的任务。 [申请项目记录](application-workflow.md)

## 怎样把竞赛写成可讲的项目

优先考虑与目标专业匹配、有明确主办方、公开规则、实质评审和可验证结果的高水平竞赛。用户举例包括全国大学生数学建模竞赛、全国大学生市场调查与分析大赛和ICPC国际大学生程序设计竞赛。数模和市调可争取全国奖项，按当届章程、奖项证书及盖章核验等级。市调部分省赛阶段会产生国赛三等奖，参加阶段和最终奖项分别记录。ICPC按证书和主办方赛程写清实际赛站或阶段。 [数模章程](https://www.mcm.edu.cn/html_cn/block/44e92058f537729c6b6a62a3662ee417.html) · [市调广东赛区通知](https://jwc.jnu.edu.cn/2026/0320/c6765a852062/page.htm) · [ICPC分级规则](https://icpc.global/regionals/rules)

同一成果分别记录两种用途。校内附加分依据当届学院认可的赛事、证书级别及分值。外校申请用作品证明实际训练和项目能力，能拿出数据或题目、报告、程序、获奖证书及贡献说明时优先。中国高等教育学会的竞赛评估目录和吉财当届推免分类分别查证。使用A类标签时填写认定机构、年份和具体文件。 [竞赛评估报告](https://heec.cahe.edu.cn/news/cy-zxdt/16186.html) · [本校竞赛认定](research-recognition.md)

简历和面试可按“问题、数据或输入、方法、本人完成的工作、结果、局限”介绍比赛项目。按真实属性写作竞赛项目、科研训练或论文，并区分报告、投稿、录用和见刊。数模可展示假设、对照和验证，市调可展示问卷或抽样及数据质量，ICPC可展示算法、实现和复杂度分析。选与目标专业最贴近的材料深入准备。

## 从大一排到申报季

| 阶段 | 优先行动 | 可检查成果 |
|---|---|---|
| 大一上 | 把必修课初修、加权均分和专业排名放在首位，同时准备英语 | 已核课程性质、学分、初修状态及英语备考计划 |
| 大一下至大二上 | 继续争取更高学业排名，大一下开始选赛、组队和做基础训练 | 可核赛事与赛程、分工、练习作品及成绩单 |
| 大二下 | 延续学业优先，主动联系本校导师开展科研训练，明确一项可在学期内推进的问题 | 阅读笔记、数据来源、研究计划、初步代码或实验记录 |
| 大三上至寒假 | 在大三下开始前争取形成可展示成果，更新排名和外语证据 | 研究报告、复现代码、海报或论文初稿，按实际状态记录 |
| 大三下至大四申报季 | 持续维护成绩，完成项目筛选、简历、成果材料、面试训练和报名 | 已核接收条件的项目表、目标导师表、个人贡献材料及各批次状态 |

## 怎样联系目标导师

研究经历与导师方向的匹配是研究型项目选校和沟通的重点。先用院系官网导师页、招生目录及公开论文确认导师的招生专业和近期方向。选择与本人训练相关的一到两项工作，写明共同的研究问题、方法或数据，再把自己的项目和可承担工作说明白。目标院校如有统一联系安排，按该流程办理。 [申请流程与状态](application-workflow.md)

邮件草稿可用三段。第一段写本科专业、目标项目、排名与外语的关键事实。第二段用一个可核验的研究或比赛项目说明本人贡献，并具体对应导师的工作。第三段询问该方向当年是否接收推免、适合怎样准备或交流，附简历及可公开成果。联系结果单独记为未联系、已发送、已回复或已交流，接收结果按正式系统及公示记录。实际发送邮件需用户明确指令。

## 补充可参考的申请个案

东北师范大学数学与统计学院2027年应用统计案例已收录一轮预推免考核、拟录取与候补分组，以及电话后填报志愿、确认复试和确认待录取的流程。山东大学威海校区数学与统计学院的同届案例对应运筹学与控制论，记录线上夏令营宣讲与秋季线下面试。据用户了解，该届学院各专业使用同一考核标准。 [东北师范大学项目记录](targets/a.md#东北师范大学) · [山东大学威海校区项目记录](targets/c.md#山东大学威海校区)

有亲历材料时，按院校、院系、专业、届别和批次记录。优先补三类细节。排名证明来不及开时，记录接收方允许的临时材料和补交结果。复试复盘记录实际考核环节、用时、项目追问和用得上的准备。候补或确认撞期时，分别记录院方联系、系统通知和实际截止。个案保留出处和适用范围，判断当批次条件仍查该项目公告、招生单位答复及系统通知。 [申请流程](application-workflow.md)
