# 推免申请研究计划

按目标项目通知确定语言、篇幅、必填栏和提交格式。用下列骨架起草一项有条件开展的研究，提交前替换所有【字段】。未取得的数据、未开展的分析和预期产出使用计划语气。

## 题目与研究问题

**拟题**　【研究对象与核心问题】

在【情境及时间范围】中，【研究对象】面临【具体问题】。我计划考察【可观察现象、待检验假设或拟证明命题】，并以【指标、评价标准或可检验条件】判断结果。研究范围先限定在【单位、群体、地区或模型条件】，拟回答【一个主问题】。

已有研究用【经核实的文献与结论】处理了【相关问题】。本计划聚焦【仍需核查的差异或缺口】，预期提供【适度的证据、验证或方法比较】。如无法确定创新性，可把目标写成复现、检验适用条件或补充一个可明确界定的场景。

## 前期准备与项目匹配

在【已完成课程、项目或实践】中，我负责【本人具体工作】，使用【确实掌握的工具或方法】完成【可核验的产物】，并遇到【尚待改进的问题】。这些经历为【研究计划中的环节】提供准备。仍需补足【知识或技能】，拟通过【课程、复现、实验或文献训练】完成。

目标项目的【公开可核的研究方向、课程或训练资源】与【计划中具体环节】相关。注明来源和适用时间，按【已具备／计划申请／待确认】区分研究条件。

## 资料与可行性

| 核查项 | 填写内容 |
| --- | --- |
| 资料或研究对象 | 【数据集、档案、实验输入、数学对象或公开基准】 |
| 获取与使用 | 【来源、当前获取状态、授权或使用范围、核查日期】 |
| 样本与变量 | 【单位、时间范围、核心字段与标签】。实际覆盖不足时写【待核缺口】 |
| 可行性检查 | 【小样本试读、重复记录、缺失、样本偏差、权限、设备或算力】 |
| 可替代输入 | 【可获取的替代来源、替代对象或缩小的研究范围】 |

涉及受限或个人数据时，写清【可使用条件与匿名化安排】。涉及理论或方法研究时，可改填【基本假设、符号、已有定理和可验证实例】。

## 方法与验证

1. **界定任务。** 用【描述、关联、预测、机制检验、理论证明或实践评估】表述目标，说明【观测条件、关键假设与评价尺度】。
2. **建立比较。** 先做【可复现的简单基线、常规方法或代表性文献方案】，再用相同的【样本、任务、指标或假设】比较【计划采用的方法】。写清采用新方法的理由。
3. **检查结果。** 按研究设计选用【独立验证、时间或分组划分、稳健性检查、反例、仿真或复现】。记录【评价指标或判定规则】，说明怎样防止数据泄漏、选择偏差或不公平比较。
4. **交代边界。** 说明【潜在混杂、测量误差、样本覆盖、外推范围或假设限制】，以及这些约束下能回答的问题。若拟做因果判断，先说明识别条件及其可检验性。若关键条件无法支持，收窄到资料能回答的描述、关联或其他适当目标。

| 阶段 | 工作与交付 | 检查点或备选路径 |
| --- | --- | --- |
| 【起步阶段】 | 【阅读记录、数据或资料清单、问题定义】 | 【何时确认关键字段、授权或研究条件】 |
| 【试做阶段】 | 【最小样本、基线复现、证明草稿或可行性报告】 | 【若未取得资料或基线不可复现，改用什么】 |

| 【整理阶段】 | 【技术报告、合规可共享的复现材料或展示稿】 | 【注明预计完成时间、适用范围与后续训练】 |

若到【判断时点】仍缺【关键数据、权限或方法条件】，改做【公开资料、较窄问题、复现或仿真方案】。同时明确备选方案能支持【结论范围】，以及原问题中【仍待回答的部分】。

## 按培养类型调整

- 学术型硕士可把计划聚焦在【一个研究问题、一个可核的数据或资料来源、一次完整的比较或验证】。
- 专业型硕士可写明【实际使用者、场景约束、可交付成果和使用验证方式】，并交代研究证据与应用建议之间的关系。
- 直博可增加【阶段性研究问题、训练缺口和可验证的推进条件】，说明先完成哪一个试做项目，结果怎样影响后续方向。

文献仅保留实际核实的【作者、题名、年份、来源】。引用、链接和成果状态在定稿时与原始证据核对。
