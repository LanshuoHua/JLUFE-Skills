# 课程加权平均分复算

脚本使用 Python 3 标准库，读取本地 UTF-8 JSON，结果输出到终端。课程范围需要先按适用学院的培养方案、统计学期和推免细则确认。脚本适用于采用学分加权的百分制初修成绩。

从技能根目录运行示例。

```powershell
python scripts/weighted_average.py assets/course-input.example.json
```

示例是合成数据，两门计入课程的计算为 `(3 × 80 + 2 × 90) / 5 = 84`。其中一门必修实践课和一门选修课的初修成绩都低于60分。两门均排除在均分之外，必修低分名单只列该实践课。

## 吉财的课程范围

校级办法U01第9条检查全部必修课程初修是否及格，第10条用第三学年结束前应修的理论必修课初修成绩计算加权均分。T05补充了理论必修的模块和实践课处理。每门课分别标记课程性质和计分归属。 [校级办法第9至10条](https://newtjxy.jlufe.edu.cn/info/1135/2971.htm) · [来源目录](policies/catalog.json)

| 课程 | 必修初修资格检查 | 理论必修加权均分 |
|---|---|---|
| 通识必修、学科必修、专业必修中的理论课 | 查初修是否及格 | 按培养方案统计至第三学年结束前应修课程 |
| 必修实践课 | 查初修是否及格 | 排除 |
| 军训、体育等校规列明项目 | 按校规检查通过情况 | 排除 |
| 选修课程，包括选修实践课 | 单有选修挂科时继续评估其余资格条件 | 排除 |

逐课归类以对应年级培养方案、成绩单及学院确认口径为准。课程模块名称用于定位，再核实该课的理论或实践属性。理论与实践混合开设的课程，使用学院核定的纳入方式和学分。初修挂科、补考通过、重修通过分项记录。

## 准备实际数据

复制示例到用户的个人工作目录。每门课用唯一 course_id 表示，保留初修成绩，与补考／重修记录分别核验。include_in_average 由学院确认的范围决定。required 表示是否属于必修课程。仅在范围已确认后把 scope_confirmed 设为 true，并在 scope_source 填写学院、届别、依据条款和课程集合的确认来源。

必修实践课填写 `required: true` 和 `include_in_average: false`。选修课两个字段均填 `false`。计入均分的理论必修课两个字段均填 `true`。

credits 使用已确认学分。initial_score 使用百分制初修成绩。五级制先按适用规则换算，个人记录保留原始等级。办法只列优秀、良好、中等、及格的换算。初修记为“不及格”且无分值时，资格审核直接记录未通过，均分所需分值待教务确认。未计入均分的课程可将未知成绩写为 null，必修未知项会单列。计入课程缺少数值成绩时停止计算。排除课程学分缺失时，可在脚本之外核对该课的初修及格状态，并标记脚本输入未覆盖全部课程。

可输入全部必修课程并明确排除项，以便看到被排除课程中的初修低分。输入仅含部分课程时，输出中的低分／未知列表也仅覆盖这部分输入。输入的 required 和 include_in_average 均为显式布尔值。

## 解释结果

公式为 `Σ(初修百分制成绩 × 学分) / Σ学分`。脚本返回计入与排除的课程编号、学分和加权积合计、40位运算精度下的平均值，以及四位小数展示值。最终成绩精度与排名采用学院规定，展示舍入不能替代其正式计算口径。

required_course_scores_below_60 列出所提供必修记录中低于60分的初修成绩，便于结合通过标准核查。空列表只能说明输入中没有该类记录。教务排名、其他资格条件、奖项认定和推免名额需要继续核验。

上游材料如只能提供GPA或已汇总平均分，先取得符合口径的课程明细，或直接使用学校签章的正式排名／分数并标明来源。跨学校的成绩换算和加分公式应另行确认。
