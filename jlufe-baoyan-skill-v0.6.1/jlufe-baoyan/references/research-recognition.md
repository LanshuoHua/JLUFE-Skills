# 竞赛与学术期刊认定依据

2026-11-10核验。先匹配[统数学院当届规则](statistics-policy.md)，再使用本页目录判断成果。学校期刊等级、学院推免资格、竞赛获奖层级分别核验。材料版本、查证范围和公开复核入口见[来源目录](policies/catalog.json)。

## U06：2024年3月竞赛名单

U06为本地核验过的2024年3月历史竞赛名单，共116条。表头为编号、赛事名称和校内组织单位。现行赛事等级、推免分值和适用届别须查当届完整文件。下表保留与统数学院较相关的历史定位信息。

| 示例 | 原件位置 | 可以证明 | 不能据此证明 |
|---|---|---|---|
| 全国大学生市场调查与分析大赛 | B79；C79为统计学院 | 进入该版名单及校内组织部门 | 个人获的是国赛还是省赛、主办方资格、个人分值 |
| 全国大学生统计建模大赛 | B80；C80为统计学院 | 同上 | 当前届别采用该表或所有赛道均计分 |
| 全国大学生数学建模竞赛 | B116；C116为应用数学学院 | 同上，原件赛事名称原样保存 | 名称含“全国”不等于所有证书都按国家级计分 |
| ACM-ICPC国际大学生程序设计大赛 | B25，C25为管理科学与信息工程学院 | 进入该版名单及校内组织部门 | 原统计当届是否计分，具体赛站及获奖等级 |

赛事名称检索可以容纳简称，但确认时逐项核对全称、年份、赛道、举办方、盖章、奖级、参赛单位、团队人数与作品。C列为校内组织部门，不作为校外主办方证明。名单列入、与专业相关、学院加分三个条件分别记录。

## U05：2025年版期刊分类目录

本地核验的28页材料文号为吉财大发〔2025〕124号；第1页落款2025-06-20，第28页版记2025-06-23印发。它是扫描件，已逐页分段目视核对。本库提供规则与页面索引，**没有声称已完成全目录逐刊OCR或完整刊名结构化**；未在摘要中出现的刊物须回看原页。

2026-11-10在学校官网、科研处域名范围检索文号、2025/2026目录、修订、更正、调整，未找到该文件官方发布页及后续替代公告；这不能证明不存在更新。当前依据是用户提供原件，判断具体论文前继续查现行科研处通知。

### 版本与一般规则（第2–4页）

- 中外文期刊分A、B、C、D、E五类，其中A细分A++、A+、A、A−，总计八级。原统计推免表只有五类分值，保留学校的细级标签及其A类归属，不自创八档推免分数；最终类别与成果资格由学院核定。
- 第4页规定新版自发布之日起实施，旧《2021版》（吉财大发〔2020〕199号）同时废止，但设过渡期至**2025-12-31**，期间新旧目录均有效，论文发表等级从高认定。历史论文的具体认定时点、目录版本须核实，不能仅因申请发生在2026年就抹去过渡条款，也不能把过渡期无限延长。
- 第4页规定，被全国哲学社会科学工作办公室、国家自然科学基金委员会、教育部、科技部、中国科学院列入预警或黑名单的期刊，自2026年名单发布之日起从学校目录淘汰剔除。须另查对应年度名单、正式发布时间和科研处执行认定，不能只拿2025静态表保证现在仍认可。
- 同一期刊两种语言发表的同一论文计1篇，同一论文对应多级时就高。未解释期刊由同行专家评议、校学术委员会表决认定，科研处解释目录。
- 第2–3页含针对**学校教师**的独立／第一作者要求及特定中文A++、A+、A列举期刊第二、第三作者降级认定办法。这是科研认定条款，**不能移植为学生推免非第一作者也可加分**；学生另按U02或适用院规。
- 第3页规定C类以上研究文章原则上5000字，D类研究文章4000字／报纸理论版2000字，E类研究文章3000字／报纸理论版1500字。文章类型、计字口径及推免是否认可仍需科研处、学院审定。
- 认定期刊上5000字以上会议综述、译文等降一级；讨论纪要、人物访谈、读后感、书评、非学术论文式商榷答辩、彩（中）页不认定。SCI、SSCI收录的**会议摘要不认定**，不能用检索收录代替成果类型审查。
- 与中文期刊同名的网络版，内容与纸质版一致按纸版定级，不一致降一级；中文期刊英文版同级认定。D及以上中文期刊增刊按中文E认定，中文E增刊不认定。这些只是目录规则，不单独保证学生论文可用于推免。

### 分类框架（第5–6页）

| 等级 | 外文期刊框架 | 中文期刊框架 |
|---|---|---|
| A++ | Nature、Science | 中国社会科学 |
| A+ | 列举24项，含特定刊物及Nature、Science开头子刊条目；逐项读原表 | 中国科学、新华文摘（全文转载）、求是 |
| A | 外文列举目录（第24–28页） | 中文列举目录（第7–8页） |
| A− | 不在以上列举中的SSCI（JCR分区）／SCI（中国科学院分区）一区 | 无 |
| B | SSCI（JCR）／SCI（中科院）二区；A&HCI学术期刊 | 中文B目录（第8–10页） |
| C | SSCI（JCR）／SCI（中科院）三区 | 中文C目录（第10–22页） |
| D | SSCI（JCR）／SCI（中科院）四区 | CSSCI来源期（集）刊、CSCD核心库，另含规定转载／摘编文章、《中国社会科学报》学术文章及《税务与经济》等，逐项见第6页 |
| E | EI收录**期刊**、CSCD扩展库英文期刊 | 北大《中文核心期刊要目总览》、CSSCI扩展版、CSCD扩展库中文期刊等，完整条件见第6页 |

SSCI与SCI使用的分区体系不同；不要将SCI的JCR Q1直接等同本表SCI一区。具体分区年份、大类／小类取法、重复收录未明确时保留待核。EI会议论文不能仅因EI收录按“EI收录期刊”处理。目录未提供CCF分级到本校等级的直接换算，不能自行添加。

### 审核一篇论文的顺序

1. 保存刊名及CN／ISSN、文章题名与类型、正式发表日期、作者顺序、第一作者单位、发表页面或检索证明。录用和发表分开。
2. 匹配目录版本及过渡条款，逐页定位列举刊物；非列举刊物核对相应索引与指定分区体系、年份。检查当年预警及剔除情况。
3. 套用适用院规的专业相关、作者、单位、时间与成果审查条件。科研目录中教师的作者优惠不套给本科推免。
4. 经学院核准后进入候选原始分，处理同一方面取一项／同作品去重，再按该院规则汇总和折算。资料未明时输出缺口及条件性结果，不保证认定。
